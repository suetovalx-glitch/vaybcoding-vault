# Пайплайн raw → wiki

## Summary

Как именно в этом vault сырьё превращается в структурированное знание. Это **конкретная реализация** [[wiki/concepts/llm-wiki-template|LLM Wiki шаблона]] в данном проекте, с учётом локальных соглашений и ограничений.

## Current Understanding

### Зоны хранения

```
raw/                          # неизменяемое сырьё
  Clippings/                  # web-clips, шпаргалки, статьи
  Сборник/                    # собранные материалы по темам
  Telegram/                   # посты и файлы из Telegram
  Templaters/                 # шаблоны заметок
  VPS/                        # заметки по серверам
  Учеба/                      # обучающие материалы
  Lora/, AlisaAI/, Excalidraw/, PDF/, Tags/
  _about.md                   # описание зоны

wiki/                         # структурированное знание
  _about.md                   # описание зоны (обновляется по мере роста)
  index.md                    # мастер-каталог
  log.md                      # append-only журнал
  overview.md                 # карта и связи верхнего уровня
  sources/                    # по странице на каждый ингест-источник
  concepts/                   # концепты и фреймворки
  entities/                   # инструменты, продукты, модели, провайдеры
  queries/                    # durable-ответы на вопросы
  comparisons/                # сравнительные разборы
  timelines/                  # хронологии
  lint-reports/               # отчёты проверок
```

### Поток обработки

```
[внешний источник]
    ↓
[raw/]                              # только запись, никогда не правим
    ↓ ingest
[wiki/sources/<date>-<title>.md]    # саммари с метаданными
    ↓
[wiki/concepts/*]                   # концепты, использованные в источнике
[wiki/entities/*]                   # сущности, упомянутые в источнике
    ↓
[wiki/overview.md]                  # обновляется, если меняется картина
[wiki/index.md]                     # обновляется всегда (каталог)
[wiki/log.md]                       # append-only запись о ingest
    ↓
[wiki/lint-reports/<date>-lint.md]  # периодический health-check
```

### Триггеры операций

- `ingest` — пользователь даёт команду «обработай raw/<файл>» или maintenance-coworker находит новый файл.
- `query` — пользователь задаёт вопрос. Если ответ имеет durable-ценность → сохраняется в `wiki/queries/`.
- `lint` — maintenance-сеанс раз в ~2 дня.

### Правила обработки

- **Не модифицировать `raw/`** (по CLAUDE.md и по здравому смыслу — сырьё иммутабельно).
- **Предпочитать редактирование существующих wiki-страниц** созданию новых.
- **Русифицировать** всё содержимое wiki, кроме профессиональных терминов.
- **Не плодить дубли** — если страница уже есть, дополняем её.
- **Не делать страницы-однодневки** — если в источнике одна мысль, она идёт в существующую concept-страницу, а не в новую.
- **Снабжать wiki-ссылками** (`[[page-name]]`) всё, что пересекается с другими страницами.

### Что пока не покрыто пайплайном

- Не заведена `raw/sources/` и `raw/assets/` подпапками — сырьё сейчас разложено тематически (`Clippings/`, `Сборник/`, `Telegram/` и т. д.). Это работает, и трогать без причины не нужно.
- Нет `AGENT.md` (упомянут в CLAUDE.md сессионном чеклисте) — пока не нужен, при необходимости заведём.
- Нет Dataview-дашборда и Charts View — отложено.

## Contradictions / Uncertainty

- В реальности сырьё разложено по «источникам» (`Clippings/`, `Telegram/`), а не по типам (`articles/`, `transcripts/`). Это удобнее для пользователя, но означает, что в `wiki/sources/<date>-<title>.md` мы фиксируем исходный путь, а не привязываемся к типовой подпапке.
