## Core Claims

1. **Архитектура «AI-агент управляет группой VPS»** — устойчивый паттерн: Control VPS (на нём живёт агент) + Target VPS 1/2/3 (целевые серверы, на них только инструменты и SSH-доступ).
2. **Список типовых задач для AI-агента** на VPS: мониторинг метрик (CPU/RAM/диск/сеть), бэкапы сайтов (rsync + архивация), перезапуск сервисов при падении, обновление пакетов по расписанию, проверка SSL-сертификатов, ротация логов.
3. **Доступ по SSH-ключам** между VPS обязателен, иначе агент превращается в «помеху безопасности».
4. **Удобный `~/.ssh/config` на Control VPS** — чтобы агенту и человеку не приходилось запоминать адреса.
5. **Self-hosted доступ к дашборду** через SSH-туннель (`localhost:9120` на desktop) — обходной путь, пока нет публичного URL.
6. **Cloudflare Tunnel** — современная замена SSH-туннелю: бесплатный публичный URL без покупки домена, без nginx, выживает после ребута сервера.

## Key Evidence / Details

### SSH-конфиг (фрагмент из источника)

```text
Host vps1
  HostName ...
  User ...
  IdentityFile ~/.ssh/...
```

### Подключение Hermes Desktop через SSH-туннель (логика из `raw/Без названия.md`)

```
сервер → Hermes → dashboard с basic auth → SSH-туннель → Desktop на 127.0.0.1:9120
```

### Cloudflare Tunnel (из Telegram-кейса)

- 5 минут чистой настройки.
- Без покупки домена, без nginx.
- Постоянный URL, не падает после ребута сервера.
- Работает с ноутбука / телефона / планшета.
