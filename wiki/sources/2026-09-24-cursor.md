## Core Claims

1. **Cursor — AI-first IDE**, форк VS Code от Anysphere, перестроенный «с нуля вокруг AI». Основан в 2022 году четырьмя студентами MIT. Оценка компании ~$29,3 млрд.
2. **Cursor Tab** — предиктивные дополнения, бьющие по целым блокам. ~72% acceptance rate, латентность 50–150 мс.
3. **Composer 2 (Cmd+I)** — мульти-файловое редактирование с визуальным diff до применения. На 8 файлах — «production-ready 4/5».
4. **Agent Mode** — автономное выполнение: читает кодовую базу, выбирает файлы, запускает терминал. ~$0.04 за шаг, сложная задача = $2–5.
5. **Background Agents (Cursor 2.0)** — параллельные агенты в облачных VM, до 8 одновременно на git worktrees. Запускаются из Cursor, Slack, телефона.
6. **BugBot Autofix** — авто-ревью + авто-фикс PR.
7. **Rules, Plan Mode, Hooks** — постоянный контекст через `.cursor/rules`, режим «сначала план», расширение lifecycle.
8. **MCP-экосистема** — 30+ плагинов (Atlassian, Datadog, GitLab, Glean, Hugging Face, monday.com, PlanetScale).
9. **Privacy Mode** — даже на free-плане, но AI-запросы всё равно идут через backend Cursor.

### Производительность

- 2–4 ГБ RAM на средний проект.
- На 45K+ строк monorepo — зависания при индексации, лаги при AI-операциях.
- Форк VS Code отстаёт от официального VS Code на 1–2 месяца.

### Что Cursor делает хорошо

- Multi-file refactoring (Composer 2).
- Visual diff до применения.
- Импорт настроек VS Code в один клик.
- 200K token codebase indexing.

### Известные проблемы

- Кредитная система непредсказуема для power users.
- AI-галлюцинации (устаревший синтаксис, deprecated API).
- Нет on-premise варианта.
- Отсутствие нативной GitLab-интеграции.
