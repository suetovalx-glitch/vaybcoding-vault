## Core Claims

1. **VS Code остаётся базовой средой для AI-ассистированной разработки.** Источник перечисляет основные подсистемы, в которые встраиваются AI-инструменты.
2. **Workspace Trust** — модель доверия, важная при работе с автономными агентами.
3. **Remote Development** (SSH / туннели / WSL) — критическая подсистема для запуска агентов на удалённых машинах.
4. **Контейнеры для разработки** — Dev Containers как способ изоляции агентских окружений.
5. **API расширений** — основа для интеграции AI-ассистентов.

## Key Evidence / Details

- Основные подсистемы: редактор ядра, IntelliSense, рефакторинг, навигация, настройки и их синхронизация, сочетания клавиш, расширения и Marketplace, профили, сниппеты, рабочие пространства, отладка, тестирование, задачи, встроенный терминал, Git, Remote Development, контейнеры.
