## Core Claims

1. **«Pantheon Release»** (v0.21.0) — между v0.20.0 и v0.21.0: ~5 800 коммитов, ~2 475 merged PR, ~5 680 файлов изменено, ~869 000 insertions, ~2 100 issues closed, 760+ контрибьюторов.
2. **Bot Mode** — bundled в desktop-приложении: каждый профиль агента получает имя, аватар, место в общем roster. Discord-style group chats с @-mention.
3. **`hermes peer`** — bot-to-bot DM между Hermes-агентами через handle.
4. **Cron с памятью:** scheduled jobs загружают и обновляют persistent memory, `continuity=true` несёт output предыдущего run в следующий, monitor-mode jobs пропускают LLM если ничего не изменилось.
5. **Live subagent orchestration:** `delegate_task` умеет list running children, steer mid-flight, stop early with partial result. 250 iterations, 10 concurrent children по умолчанию.
6. **MCP Command Center:** drag-in «paste anything» import, background health checks, fleet cost/usage overlay, `hermes://` deep links.
7. **Agent drives desktop browser** — navigates, clicks, reads напрямую.
8. **6 новых провайдеров:** Actual Computer, CommandCode (GOAT/Pro/Max), Meta Model API (Muse Spark), Tencent TokenPlan, Nebius Token Factory, Ramp Router.
9. **Безопасность:** protected agent-instruction files (AGENTS.md, skills, memory stores) всегда требуют write approval. Deep redaction sweep.
10. **Метрики:** ~85 merged PR в день в этом окне.

## Key Evidence / Details

### Заявленная позиция (из README)

> The self-improving AI agent built by Nous Research. The only agent with a built-in learning loop — it creates skills from experience, improves them during use, nudges itself to persist knowledge, and searches its own past conversations, and builds a deepening model of who you are across sessions.

### Ключевые фичи верхнего уровня

- **Closed learning loop** — agent-curated memory, autonomous skill creation, FTS5 cross-session recall, Honcho dialectic user modeling.
- **Runs anywhere** — local, Docker, SSH, Singularity, Modal, Daytona, Vercel Sandbox. Serverless persistence (Daytona, Modal).
- **20+ каналов:** CLI, Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Mattermost, Email, SMS, DingTalk, Feishu, WeCom, Weixin, QQ Bot, Yuanbao, BlueBubbles, Home Assistant, Microsoft Teams, Google Chat.
- **Nous Portal** — 300+ моделей, Tool Gateway (web search, image gen, TTS, cloud browser) под одной подпиской.
- **Модель-провайдеры:** Nous Portal, OpenRouter, OpenAI, Anthropic, любой OpenAI-совместимый endpoint.
- **Skills ecosystem:** открытый стандарт `agentskills.io`, Skills Hub.
- **MCP integration** — 60+ built-in tools + toolset system.
- **Bot Mode** (выделено в v0.21) — durable team of specialist Bots, общие group chats, @mentions.

### Миграция с OpenClaw

`hermes claw migrate` — автоимпорт из `~/.openclaw`:

- SOUL.md, Memories (MEMORY.md, USER.md), Skills, Command allowlist, Messaging settings, API keys, TTS assets, AGENTS.md.

Флаги: `--dry-run`, `--preset user-data`, `--overwrite`.
