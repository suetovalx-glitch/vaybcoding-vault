## Core Claims

1. **Hermes Agent** от Nous Research — самообучающийся (в смысле «накапливающий опыт») агент, который сохраняет важные факты, ищет информацию в предыдущих диалогах, превращает удачные сценарии в навыки и использует их дальше.
2. **Архитектура:** LLM-«мозг» (GPT / Claude / Gemini / DeepSeek и др.) + агентная обвязка. Цикл: запрос → выбор инструментов → выполнение (терминал, файлы, браузер, MCP) → возврат результатов → сохранение полезного в память/навык.
3. **Интерфейсы:** CLI, Telegram, Discord, Slack, WhatsApp, Signal. К одному агенту можно подключиться из любого канала.
4. **«Самообучение» ≠ fine-tuning.** Память и навыки — это внешние файлы и подсказки, а не дообучение весов.
5. **Память:** два файла — `MEMORY.md` (короткие факты о среде и решениях) и `USER.md` (предпочтения пользователя). Объём намеренно ограничен.
6. **История сессий:** полная история + инструмент `session_search` (полнотекстовый поиск + LLM-пересказ).
7. **Навыки (Skills):** длинные пошаговые инструкции в формате `SKILL.md`. Агент может создавать навыки сам, можно устанавливать из Skills Hub, переносить между совместимыми агентами.
8. **Планировщик:** cron-выражения и формулировки на естественном языке. Возможен режим без LLM (скрипт + доставка результата, без расхода токенов).
9. **Делегирование:** агенты создают изолированных сабагентов и распределяют независимые части задачи.
10. **MCP:** встроенная поддержка Model Context Protocol — внешние документы, БД, Git-репозитории подключаются без хардкода инструментов.

## Key Evidence / Details

### Возможности (по статье)

- Работа с кодом и файлами: изучение структуры, поиск багов, точечные правки, запуск простых тестов.
- Выполнение команд: установка зависимостей, запуск скриптов, чтение логов, автоматизация рутины. ⚠️ Агент получает реальные права — нельзя бездумно давать ему прод-ключи.
- Поиск и исследование: веб-поиск, извлечение содержимого страниц, работа через браузер.
- MCP-пример: подключение MCP-сервера Amvera — управление облачными проектами из того же диалога, в котором агент пишет и проверяет код.

### Запуск

- Минимальные требования: 1 ГБ RAM + 1 ядро. Комфорт: 2–4 ГБ + 2 ядра. Браузерная автоматизация через Chromium требует ≥ 2 ГБ.
- Пример развёртывания: Amvera Cloud (через `amvera.yml` + официальный образ `nousresearch/hermes-agent:latest`).
- Переменные окружения: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USERS`, `OPENROUTER_API_KEY` (или `OPENAI_API_KEY`), `SERPAPI_KEY` (опционально).
- ⚠️ Не включать `TELEGRAM_ALLOW_ALL_USERS=true` для публичного бота.
- ⚠️ Не включать `HERMES_YOLO_MODE=1` в проде — отключает почти все подтверждения опасных команд.
- Стартовые команды: `/sethome`, `/model <модель>`.
- `persistenceMount: /opt/data` — обязательно, иначе навыки и память теряются при пересборке.

### Безопасность (минимальные правила)

1. Запускать Hermes в отдельном проекте, не передавать лишние ключи.
2. Ограничивать доступ к Telegram через `TELEGRAM_ALLOWED_USERS`.
3. Не включать `HERMES_YOLO_MODE=1`.

### Частые проблемы

- Бот запустился, но не отвечает → проверить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_ALLOWED_USERS`; нельзя запускать два инстанса с одним Telegram-токеном.
- HTTP 402 / max_tokens — бесплатные маршруты OpenRouter не покрывают лимит. Решение: уменьшить лимит вывода, выбрать другую модель, попробовать free-модели.
- No inference provider configured → выполнить `/model`.
- После пересборки пропали навыки/память → проверить `persistenceMount: /opt/data`.

## Дополнительный контекст (из Telegram-материалов)

- **Кейс «Полгода я платил...»** — автор (Роман Сухов) перешёл с OpenClaw на Hermes. 4 причины перехода: автоматическое обновление памяти, авто-создание скиллов из повторяющихся действий, канбан в браузере вместо терминала, работа на подписке ChatGPT, а не на API.
- **Кейс «Гермес у меня дорос...»** — 6 параллельных сабагентов, работающих ночью. Внутренний поиск по личным заметкам и конспектам, оплата токенов за память = 0.
- **Кейс «Хватит лезть в терминал...»** — Cloudflare Tunnel + Hermes даёт URL-доступ к дашборду/канбану/cron-задачам с любого устройства за 5 минут, без покупки домена.
