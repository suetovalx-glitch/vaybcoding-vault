## Core Claims

1. **LLM Wiki (по шаблону Андрея Карпати)** — это паттерн организации базы знаний с LLM-куратором. Три уровня: `raw/` (неизменяемые исходники), `wiki/` (LLM-поддерживаемые страницы), `CLAUDE.md` (операционная схема).
2. **Три рабочих операции:** `ingest` (чтение источника и создание саммари/concept/entity-страниц), `query` (ответы на вопросы пользователя), `lint` (проверка целостности вики).
3. **Pi Agent** — набор инструментов для построения AI-агентов:
   - `pi-ai` — унифицированный мультипровайдерный API для LLM + потоковые события.
   - `pi-agent-core` — обвязка: повороты, события, хуки, длительные запуски.
   - `pi-coding-agent` — интерактивный режим, режим печати, режим RPC/SDK, TUI.
