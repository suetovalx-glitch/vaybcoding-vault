## Core Claims

1. **OpenClaw — open-source персональный AI-ассистент** (Foundation, 501(c)(3)), который запускается локально и подключается к мессенджерам через единый Gateway.
2. **Каналы:** WhatsApp, Telegram, Slack, Discord, Google Chat, Signal, iMessage, IRC, Microsoft Teams, Matrix, Feishu, LINE, Mattermost, Nextcloud Talk, Nostr, Synology Chat, Tlon, Twitch, Zalo, WeChat, QQ, WebChat. 20+ платформ.
3. **Модели — плагины:** Claude, Codex, локальные модели. Подмена без изменения остального кода.
4. **Принцип «твой, без подвоха»:** state/память/креды — на своём железе, нет hosted-сервиса, нет токена, нет платного tier. Foundation финансируется Amazon, Lobster Computer Company, Offline Holdings, OpenAI, Red Hat, University of Michigan.
5. **Установка:** `npm install -g openclaw@latest` → `openclaw onboard --install-daemon`. Runtime: Node 24 (рекомендуется) или Node 22.14+.
6. **Gateway — единая точка:** сессии, инструменты, события, каналы. Control UI, CLI, TUI подключаются к Gateway. Companion-приложения для macOS, iOS, Android, Windows, Linux.
7. **Безопасность по умолчанию:** DM-pairing (неизвестный отправитель получает код подтверждения), инструменты работают на хосте для main-сессии, sandbox через Docker/SSH/OpenShell для non-main, явный `HERMES_YOLO_MODE`-аналог отсутствует (по умолчанию всё подтверждается).
8. **Skills, plugins, MCP:** skills в `~/.openclaw/workspace/skills/`, MCP поддерживается, каталог расширений — ClawHub.
9. **Companion apps:** macOS menu bar, iOS/Android nodes (Canvas, камера, screen capture, voice), Windows, Linux.
10. **История:** Warelay → Clawdbot → Moltbot → OpenClaw.

## Key Evidence / Details

### Архитектура

```
Chat apps + plugins → Gateway → { Pi agent, CLI, Web Control UI, macOS app, iOS/Android nodes }
```

### Минимальный конфиг (`~/.openclaw/openclaw.json`)

```json5
{
  agent: {
    model: "<provider>/<model-id>",
  },
}
```

### Безопасность (поведение по умолчанию)

- Telegram/WhatsApp/Signal/iMessage/Microsoft Teams/Discord/Google Chat/Slack: `dmPolicy="pairing"` для неизвестных отправителей.
- Approve: `openclaw pairing approve <code>`.
- Публичные DM требуют явного `dmPolicy="open"` + `"*"` в allowlist.
- Sandbox для non-main: `agents.defaults.sandbox.mode: "non-main"`. Docker — backend по умолчанию.
- `openclaw doctor` для проверки DM-политик.

### Workspace

- `~/.openclaw/workspace`
- Injected prompt files: `AGENTS.md`, `SOUL.md`, `TOOLS.md`.
- Skills: `~/.openclaw/workspace/skills/<name>/SKILL.md`.

### Slash-команды (operator quick refs)

`/status`, `/new`, `/reset`, `/compact`, `/think <level>`, `/verbose on|off`, `/trace on|off`, `/usage off|tokens|full`, `/restart`, `/activation mention|always`.
