## Core Claims

1. **Amvera — российская PaaS-платформа** для приложений, ботов, сайтов. Деплой через `git push amvera master` одной командой или из UI.
2. **Поддержка языков:** Python, Java, Node.JS, Golang, C#, Ruby, PHP, Docker и другие окружения.
3. **Managed СУБД:** PostgreSQL (кластеры с репликацией), Redis, MongoDB, MySQL, Qdrant — от 290 ₽/мес.
4. **LLM API:** GPT 5, LLaMA 3.1/3.3 с оплатой в рублях. Бесплатное проксирование OpenAI/Claude/Gemini.
5. **AI-IDE Polide** — альтернатива Cursor (собственный продукт Amvera).
6. **Регионы:** Москва и Варшава. Варшава — обход российских региональных ограничений.
7. **SLA:** 99.9%, данные в 3 копиях, ежедневные бэкапы, автовосстановление 10–15 минут.
8. **Поминутная тарификация** — списание раз в час только за фактическое время работы.
9. **Kubernetes-оркестрация**, горизонтальное и вертикальное масштабирование.
10. **Стартовый бонус** 111 ₽ при регистрации.

### Правила диска

- 35 ₽ за ГБ / 30 дней хранения сверх лимита.
- В потребление входят: `code`, `artifacts`, `Data`, `repo`.

### Заморозка и удаление

- Автозаморозка (удаление артефактов) через 30 дней остановки.
- Если объём файлов превышает лимит — проект может быть удалён.

### Дополнительные возможности

- Сетевая связность 20–30 микросервисов без ручной настройки.
- Пользовательские домены + бесплатный SSL.
- Проксирование OpenAI/Claude/Gemini через иностранный IP — бесплатно.
