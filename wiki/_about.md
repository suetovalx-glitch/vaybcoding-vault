# Wiki

Структурированные wiki-страницы, созданные на основе материалов из `/raw`. База организована по принципу **LLM Wiki** (модель Андрея Карпати), схема зафиксирована в `wiki/sources/2026-09-19-project-claude-md`.

## Навигация

- `wiki/index.md` — мастер-каталог всех страниц.
- `wiki/overview.md` — карта знания и связи верхнего уровня.
- `wiki/log.md` — журнал операций (ingest, query, lint).

## Подпапки

- `wiki/sources/` — по одному саммари на каждый ингест-источник.
- `wiki/concepts/` — концепты, методы, фреймворки.
- `wiki/entities/` — сущности: инструменты, продукты, модели, провайдеры.
- `wiki/queries/` — durable-ответы на вопросы.
- `wiki/comparisons/` — сравнительные разборы.
- `wiki/timelines/` — хронологические реконструкции.
- `wiki/lint-reports/` — отчёты проверок базы.

## Принцип

- Сырьё из `raw/` никогда не правится.
- Новые wiki-страницы создаются только если концепт или сущность реально новые; иначе — обновляем существующую страницу.
- Все итоговые знания — на русском. Английский только для профессиональных терминов, названий инструментов, API, команд, путей.
- Каждая wiki-страница имеет минимум одну входящую и одну исходящую wiki-ссылку.
