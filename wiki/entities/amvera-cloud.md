# Amvera Cloud

## Summary

Amvera Cloud — российская PaaS-платформа для хостинга приложений, ботов и сайтов. Деплой через `git push amvera master` одной командой. Поддерживает Python, Java, Node.JS, Golang, C#, Ruby, PHP, Docker. **Основана в 2023 году**, базируется в Москве, регионы — Москва и Варшава. На сентябрь 2026 — Kubernetes-оркестрация, SLA 99.9%, данные в 3 копиях, ежедневные бэкапы.

## Current Understanding

### Возможности

- **Деплой через GitOps** — `git push amvera master`, обновление одной командой.
- **Встроенные окружения:** Python, Java, Node.JS, Golang, C#, Ruby, PHP, Docker.
- **Managed СУБД:** PostgreSQL (кластеры с репликацией и бэкапами), Redis, MongoDB, MySQL, Qdrant — от 290 ₽/мес.
- **LLM API:** GPT 5, LLaMA 3.1/3.3 с оплатой в рублях.
- **Бесплатное проксирование** OpenAI/Claude/Gemini через иностранный IP.
- **AI-IDE Polide** — собственная альтернатива Cursor (в roadmap — AI-агент по кодированию).
- **Маркетплейс сервисов:** n8n, RabbitMQ, Flowise, NocoDB, WordPress, Keycloak.

### Регионы

- **Москва** — стандартный.
- **Варшава** — обход российских региональных ограничений для Telegram/Discord-ботов и доступа к зарубежным API.

### SLA и надёжность

- 99.9% SLA.
- Данные в 3 копиях на разных серверах.
- Ежедневные бэкапы в независимом дата-центре.
- Автовосстановление при падениях: 10–15 минут, при необходимости — миграция на новые ноды.
- Допустимая нагрузка на нодах — до 50% (запас для пиков).

- **Поминутная тарификация** — списание раз в час только за фактическое время работы.
- Стартовый бонус **111 ₽** при регистрации.
- Аналогичные тарифы в Heroku стоят $7 / $25 / $50 / $250 / $500 — Amvera заметно дешевле.

### Правила диска

- Превышение лимита диска тарифицируется отдельно: 35 ₽ за ГБ / 30 дней.
- В потребление диска входят папки: `code`, `artifacts`, `Data`, `repo`.

### Заморозка и удаление

- Автозаморозка (удаление артефактов) через 30 дней остановки.
- Если объём файлов превышает лимит тарифа после заморозки — проект может быть удалён.
- Поддержание положительного баланса предотвращает удаление.

### Сетевая связность

- 20–30 микросервисов (приложений) можно развернуть без ручной организации сети.
- Пользовательские домены + бесплатный SSL.
