# hshp.host (HSHP Hosting)

## Summary

**hshp.host** (HSHP Hosting) — российский VPS-провайдер с 2021 года. Биллинг на **BILLmanager**, серверная панель — **VMManager**, виртуализация — **KVM**. Локации: Россия (Москва), Германия, Финляндия, Франция. Выбран как провайдер **VPS-2 (pi-coding-agent)** в архитектуре dual-agent-stack: тариф **DE-E2**, ID `1950834`, ~600 ₽/мес.

## Current Understanding

### Бизнес и платформа

- Российский хостер, на рынке с 2021 года, ~1 500 клиентов.
- Биллинг: **BILLmanager** (`https://my.hshp.host/billmgr`).
- Серверная панель: **VMManager**.
- Виртуализация: **KVM** (аппаратная).
- AntiDDoS «до 2 Тбит/с» включён во все тарифы.
- Безлимитный трафик.
- Поддержка 24/7 (чат, e-mail `support@hshp.host`, телефон `8 (800) 350-73-76`).
- ОС на выбор: Windows Server 2016/2019/2022, Debian 9–12, Ubuntu 16.04–22.04, CentOS 7/8/9 Stream, FreeBSD 12–14. Можно загрузить свой ISO.
- **Тестового периода нет.**
- Регистратор — **ИП Шарапов Никита Александрович** (Ростов-на-Дону), по отзывам otzovik.

### Промо-тарифы

В обзорах встречаются устаревшие `MSK-PROMO-1` и `DE-PROMO-1` (99 ₽) — проверять наличие через `GET https://hshp.host/vps` или в личном кабинете.

### Оплата

ЮMoney, Visa/MasterCard, криптовалюта (по данным kreohost.ru). WebMoney, RBK Money, PayPal — исторически поддерживались, но **на текущий момент нужно уточнять** (нет публичного платёжного прайс-листа).

### Управление и доступ

- API для автоматизации — **не публикуется**. BILLmanager имеет стандартный API (`https://my.hshp.host/billmgr?`), но документация не выложена. Если нужна автоматизация — запрашивать у поддержки.
- SSH-доступ — стандартный (порт 22 или нестандартный, зависит от тарифа).
- ISO-загрузка — поддерживается.

### Что хорошо (по отзывам)

- **Низкие цены** на VPS (один из самых дешёвых в РФ).
- **Большой выбор локаций** (RU + 3 EU).
- **AMD Ryzen 5950X** в Финляндии (4.9 ГГц, отличная частота для single-thread задач).
- **Безлимитный трафик** — для нашего сценария (Telegram gateway, MCP polling) безлимит важен.
- **AntiDDoS** включён.
- **Быстрая панель VMManager** — типичные действия (reboot, reinstall, IP) — 1 клик.

### Что плохо (по отзывам)

Это важно — фиксирую честно:

- **Средняя оценка 2.6/5** (kreohost.ru), **1.6/5** (otzovik.com), **только 10% рекомендуют**.
- **Главные жалобы:**
  - **Долгая активация** — обещают «120 секунд», реально 1–14 дней (есть кейс «активировали через 17 дней»).
  - **Поддержка медленная** — отвечают по 1–3 дня, многие тикеты висят неделями без ответа.
  - **Массовые сбои** (июль 2024) — несколько дней сервера лежали, на балансе зависали деньги.
  - **Возврат денег** — только бумажным письмом на юрадрес (ИП Шарапов Н. А., Ростов-на-Дону), не электронной почтой.
  - **IP-гео «Германия» ≠ физический ЦОД** — по факту сервер может быть в Финляндии, IP-гео подправляют через месяц. Если для задач критична геолокация — уточнять.
- **Позитивные отзывы** — есть: «7 месяцев полёт нормальный», WireGuard поднялся за час, IP чистый в спам-базах.

### Решение: подходит ли для prod-агента?

| Риск | Для нашего dual-agent-stack | Митигация |
| --- | --- | --- |
| Активация 1–14 дней | Уже активирован (id 1950834) — не актуально | — |
| Поддержка медленная | pi-coding-agent работает автономно, не критично | Локальные логи + автоматический рестарт через systemd |
| Массовые сбои | Telegram-бот может лежать часами | Дубль на AdminVPS (Hermes), swap bot-роли вручную |
| IP-гео не совпадает | Cloudflare Tunnel требует «правильный» GEO? Нет, Tunnel работает с любого IP | Не критично |
| | | |

**Вывод:** для **экспериментального/персонального прода** — нормально. Для **коммерческого 24/7** — высокий риск.

## Почему выбран именно DE-E2

Под наш dual-agent-stack (VPS-2 = исполнитель pi-coding-agent) DE-E2 — лучший fit:

1. **2 vCPU / 4 ГБ RAM / 60 ГБ NVMe** — точно под наш конфиг из [[wiki/concepts/dual-agent-stack]] (Chromium + Node 22 + 6 MCP-серверов требуют 4 ГБ).
2. **Германия/Финляндия** — EU-IP, чистый, обходит RU-блокировки OpenRouter/Cloudflare/GitHub.
3. **500 Мбит/с канал** — для git-push и OpenRouter-стриминга хватит с запасом.
4. **600 ₽/мес** — на 25% дешевле MSK-2 при тех же ресурсах, но с EU-IP.

## Альтернативы, которые рассматривали

- **Amvera Cloud** — российский PaaS, от 170 ₽/мес, но **не даёт прямой root-доступ** к VPS, контейнерный подход. Под нашу задачу (systemd + cloudflared + custom Docker) **не подходит**.
- **AdminVPS** (Финляндия) — VPS-1 для Hermes. Уже куплен, ~250–400 ₽/мес.
- **Aéza / Timeweb / Selectel / REG.RU** — дороже на 30–50% при тех же ресурсах, но с лучшей поддержкой.

## Contradictions / Uncertainty

- В разных обзорах локация «Германия» у hshp.host по факту физически Финляндия (по словам их поддержки в отзывах). Гео-IP-базы обновляются через ~месяц. **Не критично для нас** (нам нужен чистый EU-IP, а не конкретная страна).
- Цены в обзорах разнятся на 5–10% (то 99 ₽ промо, то 209 ₽, то 320 ₽). **Точные цены — только в личном кабинете** (`https://my.hshp.host/billmgr`).
- API для автоматизации не документирован. Если нужны автоснапшоты / автоплатёж через скрипт — запрашивать у поддержки.
- Репутация хостера низкая (2.6/5), но для нашей задачи (одноразовый деплой dev-стека) — приемлемо.
