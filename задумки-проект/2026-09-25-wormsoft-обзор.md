# Wormsoft AI — обзор провайдера LLM

**Дата:** 2026-09-25
**Источник:** <https://ai.wormsoft.ru/> и разделы документации

## TL;DR

Wormsoft AI — российский провайдер LLM по подписке с OpenAI-совместимым API (`https://ai.wormsoft.ru/api/gpt/...`). Доступен без VPN из РФ. **Точный каталог моделей не отдаётся без API-ключа** — на странице `/models` пустая таблица, реальный список возвращает только `GET /api/gpt/models` с `Authorization: Bearer YOUR_API_KEY`. Это критический блокер для принятия решения «какие модели использовать».

## Что удалось узнать

### Сам провайдер

- **Домен:** `ai.wormsoft.ru`, сервер `nginx/1.29.7` + `Express` (Node.js).
- **Эндпоинты:**
  - `GET /api/gpt/models` — каталог моделей (требует ключ).
  - Алиасы: `/gpt/v1`, `/gpt/v1/v1` (упомянуты в доке).
- **API:** совместим с OpenAI Responses API (упоминают `store: true` не поддерживается).
- **Контакты:** `info@wormsoft.ru`, `@WormsoftBot` (Telegram и MAX).

### Кредитная система vs rate limit

Согласно `/docs/llm/subscriptions`:

- **Кредиты** = сколько токенов можно потратить между сбросами. Стоимость зависит от модели.
- **Rate limit** = сколько запросов за короткое окно (например, 10/600 сек на Free).
- Оба лимита независимы — даже с остатком кредитов на 11-м запросе за 10 минут получите 429.

### Каталог моделей

- **Страница `/models` и `/docs/llm/models`** — статично пустая, JS не отрендерился.
- **`GET /api/gpt/models`** — единственный источник истины. С `Bearer probe` сервер отвечает `401 Unauthorized` (проверено `curl -i` 2026-09-24).
- **Формат моделей** (предположительно): `префикс/модель`. В примере документации указан `openai/gpt-5.4` (это синтетика, реальная модель — другая).
- **Подтверждённые пользователем модели** (из обсуждения на fediverse): `wormsoft/code/low` — собственная алиас-модель Wormsoft для кода, низкий уровень (бесплатная).

## Провайдеры, доступные через Wormsoft (предположения)

OpenAI-совместимый агрегатор в РФ обычно включает:

- **OpenAI** (gpt-4o, gpt-4-turbo, o1, o3-mini)
- **Anthropic** (claude-3.5-sonnet, claude-3-opus, claude-3-haiku)
- **Google** (gemini-2.5-pro, gemini-2.5-flash, gemini-2.0)
- **DeepSeek** (deepseek-chat, deepseek-reasoner, deepseek-coder)
- **Meta / Llama** через прокси
- **Qwen / Mistral** — реже
- **Собственные модели Wormsoft** (судя по алиасу `wormsoft/code/low`)

> **Это гипотеза на основе конвенции имён OpenRouter.** Реальный список узнаем только через `/api/gpt/models` с ключом.

## Рекомендация: как принять решение по моделям

### Шаг 1 — получить API-ключ (1 сообщение боту)

1. Открыть `@WormsoftBot` в Telegram.
2. Запросить ключ, выбрав тариф. Для начала — **Базовый (бесплатный)**, 5 000 кредитов / 20 ч / 1 запрос/мин — этого хватит на тест-драйв, но для агента будет мало.
3. Если планируется серьёзная работа — брать тариф за 1 000 ₽/мес (150 000 кредитов, 15 запросов/мин) — это разумный минимум для агентских нагрузок.

### Шаг 2 — запросить каталог моделей (1 команда)

```bash
curl -sS "https://ai.wormsoft.ru/api/gpt/models" \
  -H "Authorization: Bearer $WORMSOFT_API_KEY" | jq '.data[] | {id, input_modalities, capabilities}'
```

Это вернёт полный список с capabilities (vision, tools, JSON mode, и т. п.).

### Шаг 3 — запросить цены (1 команда с эндпоинтом `/pricing`)

URL пробовать `https://ai.wormsoft.ru/api/gpt/pricing` или смотреть в доках после ключа (страница `pricing-and-usage` подгружает через JS).

### Шаг 4 — выбрать модели под задачи

После получения реального списка — выбор по трём критериям:

| Задача | Что важно | Кандидаты (гипотетически) |
| --- | --- | --- |
| **Основной агент (default)** | качество кода, рассуждения, длинный контекст | `anthropic/claude-sonnet-4.5` или `openai/gpt-4o` или `anthropic/claude-3.5-sonnet` |
| **Быстрые ответы (cheap)** | низкая цена, скорость | `google/gemini-2.5-flash` или `deepseek/deepseek-chat` |
| **Vision / изображения** | поддержка картинок | `openai/gpt-4o`, `google/gemini-2.5-pro`, `anthropic/claude-3.5-sonnet` |
| **Код / рефакторинг** | хорошее качество на коде | `wormsoft/code/low` (собственная алиасная), `deepseek/deepseek-coder`, `anthropic/claude-3.5-sonnet` |
| **Рассуждения / planning** | длинный chain-of-thought | `openai/o1`, `openai/o3-mini`, `deepseek/deepseek-reasoner`, `anthropic/claude-3.7-sonnet` |

## Подходит ли Wormsoft для нашего агента?

**Плюсы:**

- ✅ Без VPN из РФ — решает большую головную боль (особенно пока VPS ещё не настроен для прокси).
- ✅ OpenAI-совместимый API — стандартный SDK работает без правок (`base_url = "https://ai.wormsoft.ru/api/gpt"` или `/gpt/v1`).
- ✅ Подписки с регулярным обновлением кредитов — предсказуемая экономика.
- ✅ Rate limits явно прописаны — удобно планировать cron-задачи.

**Минусы:**

- ❌ Без API-ключа нельзя посмотреть каталог — это плохой UX и красный флаг для прозрачности.
- ❌ Непонятно, есть ли гарантии конфиденциальности (данные идут через Wormsoft).
- ❌ Цены выше, чем у прямых API (агрегаторы берут маржу).
- ❌ Один сервис = одна точка отказа. Если Wormsoft ляжет — агент встанет.

**Рекомендация:** использовать Wormsoft как **одного из провайдеров** (для скорости и РФ-доступности), но **не единственного**. В `~/.config/pi/config.json` настроить fallback на OpenRouter / прямой OpenAI / прямой Anthropic.
