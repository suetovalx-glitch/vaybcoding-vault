# Проверка провайдера AdminVPS

Дата: 2026-09-24.
Контекст: выбор VPS для переезда агента и vault'а (планы `2026-09-24-план-переезда-на-vps.md` и `2026-09-24-план-переезда-агента-на-vps.md`).

## TL;DR

**AdminVPS — подходящий провайдер для нашего сценария**, но с оговорками:
- **Подходит для зарубежного IP** (Варшава, Франкфурт, Амстердам) — нужен для прямого доступа к OpenAI/Anthropic/OpenRouter.
- **Принимает карты РФ** — главный плюс для российских пользователей.
- **Есть Варшава** в локациях (Дата-центр LIM DC3, Tier 2+, пинг до Москвы 30–40 мс) — наш рекомендованный регион.
- **Бюджетный старт** — от 499 ₽/мес за конфиг 1 vCPU / 2 ГБ / 15 ГБ NVMe в Варшаве.

**Минусы для нашего сценария:**
- **Нет публичного API/Terraform** — автоснапшоты через cron придётся делать вручную.
- **Нет почасовой оплаты** — минимум 1 месяц, не подходит для коротких тестов.
- **Бесплатный тест только для юрлиц** — физлицу придётся платить сразу.

## Прямой доступ к LLM API

Главный вопрос для нашего кейса — будут ли доступны OpenAI / Anthropic / OpenRouter с сервера в Варшаве.

**Из авторитетных источников:**
- По статье AIlist (29.06.2026): «значительная часть сервисов вроде API Anthropic и OpenAI не открывается с российских IP» — это про российские IP, **не** про европейские.
- С европейского IP (Германия, Нидерланды) доступ к api.openai.com и api.anthropic.com работает напрямую, без VPN.
- С сервера в Варшаве доступ к OpenAI/Anthropic/OpenRouter должен работать напрямую.

**Альтернативный путь (если прямой доступ заблокируют в будущем):**
- Российский API-шлюз (GPTunnel, BotHub, VseGPT) — оплата рублями, ключ подставляется в `base_url`.
- В этом случае можно взять сервер в Москве — пинг лучше, оплата рублями к шлюзу проще.

**Рекомендация:** брать Варшаву. Если в будущем Anthropic закроет ЕС — переключиться на шлюз.

**Базовый (тест, минимальный):** Promo Варшава — 499 ₽/мес, 1 vCPU / 2 ГБ / 15 ГБ.
- Хватит для vault + cron-pull, без агента.
- Минус: 15 ГБ впритык, агента уже не поставишь.

**Оптимальный (агент + vault + перспектива):** Micro Варшава — 799 ₽/мес, 2 vCPU / 4 ГБ / 30 ГБ.

**С запасом (production):** Start Варшава — 1 289 ₽/мес, 4 vCPU / 8 ГБ / 60 ГБ.
- 8 ГБ RAM — под Docker, headless-браузер, несколько агентов.
- 60 ГБ — под GitHub Actions runners, Quartz, видео/аудио в `raw/`.

**Рекомендую начать с Micro (799 ₽)** — оптимальный баланс цена/возможности. Если окажется мало — апгрейд в Start через панель без простоя и переустановки.

## Сводка «подходит / не подходит»

✅ **Подходит, если:**
- нужен зарубежный IP для OpenAI/Anthropic по прямой;
- важна оплата картой РФ;
- достаточно KVM без оверселлинга;
- готовы платить за месяц (не нужна почасовая оплата);
- не критично отсутствие API/Terraform.

❌ **Не подходит, если:**
- нужна почасовая оплата для коротких тестов;
- нужна автоматизация через API/Terraform;
- нужны GPU-серверы (есть отдельная линейка GPU, но дорого и для локальных моделей);
- не хочется возиться с ispmanager.
