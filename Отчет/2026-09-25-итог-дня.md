### 2. Обзор провайдера Wormsoft AI

- Документ: `задумки-проект/2026-09-25-wormsoft-обзор.md`
- **Wormsoft AI** — реальный российский провайдер LLM по подписке с OpenAI-совместимым API.
- **Что знаем:** базовый URL `https://ai.wormsoft.ru/api/gpt/*`, алиасы `/gpt/v1` и `/gpt/v1/v1`, контакты `info@wormsoft.ru` и `@WormsoftBot` (Telegram/MAX).
- **Подписки:** 5 тарифов от 0 ₽/мес (5 000 кредитов / 20 ч / 1 запрос/мин) до 8 000 ₽/мес. Названия платных скрыты в дизайне.
- **Сервер:** nginx/1.29.7 + Express (Node.js).
- **Кредитная система:** отдельно от rate limit. Кредиты списываются за токены, rate limit — независимое ограничение скорости.
- **Подтверждённая модель** из чужих отзывов: `wormsoft/code/low` (собственная алиасная модель Wormsoft для кода, бесплатная).
- **Главный блокер:** каталог моделей отдаётся только через `GET /api/gpt/models` с API-ключом. Без ключа страницы `/models` и `/pricing-and-usage` пустые (JS-рендер).
- **Доказательство блокера:** `curl -i https://ai.wormsoft.ru/api/gpt/models -H "Authorization: Bearer probe"` → `HTTP/1.1 401 Unauthorized`.
- **Гипотеза о провайдерах** (без подтверждения): у Wormsoft, скорее всего, есть OpenAI, Anthropic, Google, DeepSeek + собственные алиасы — но это именно гипотеза, проверяется ключом.

### 9. Orca ADE — опциональный GUI-фронтенд (ночной блок, диалог 12)

Пользователь спросил «можем ли мы использовать Orca?» и прислал ссылку `https://www.onorca.dev`. После уточнения URL проверил `onorca.dev` через `fetch_content` — это совсем другая Orca: **Agent Development Environment (ADE)** от Stably, Inc.

#### Что это

- **Orca ADE** — worktree-first IDE для запуска нескольких AI-агентов параллельно в изолированных git worktrees.
- **Bring Your Own Agent (BYOA):** Claude Code, Codex, OpenCode, Grok, Gemini, Cursor CLI, **Pi**, **Hermes Agent**, Kimi, Qwen Code и др. — **все наши агенты поддерживаются**.
- **Ghostty-класс терминал** с infinite splits, встроенный diff-review, embedded browser, SSH remote.
- **Кросс-платформенный:** macOS / Windows / Linux + iOS/Android companion.
- **Лицензия:** MIT, бесплатный.
- **Компания:** Stably, Inc., **Y Combinator**, 78.1k stars на GitHub.

#### Что меняется для нашего dual-agent-stack

- VPS-1 и VPS-2 остаются отдельными VPS-ами.
- **Orca добавляется как опциональный GUI-слой на локальной машине:**
  - Worktree `hermes-vps1` → Hermes Agent → SSH в VPS-1.
  - Worktree `pi-vps2` → pi-coding-agent → SSH в VPS-2.
  - Worktree `my-code` → свой проект через Claude Code / Codex / Cursor CLI.
- **Что это даёт:** GUI без своего фронтенда, worktree isolation, diff-review, параллельный запуск агентов, SSH-в-VPS, browser-automation, mobile companion.

### 11. NetBird как mesh-VPN между VPS (ночной блок, диалог 14)

Пользователь спросил «мы можем использовать netbird для связи».

#### Что это

- **NetBird** — mesh-VPN на WireGuard (BSD-3, self-hosted).
- Поддерживает Linux/Windows/macOS/iOS/Android/Docker/routers.
- Identity-based ZTNA, peer-to-peer туннели между VPS.
- Каждый peer получает IP из подсети 100.64/12.

#### Три сценария интеграции

- **A: полная замена** Cloudflare Tunnel на NetBird для всей связи между VPS.
- **B: гибрид** — Cloudflare Tunnel для публичного HTTPS-фронтенда, NetBird для mesh-VPN. **Рекомендация.**
- **C: NetBird только для test-инфры** — прод остаётся на Cloudflare, test-VPS подключаются к отдельному mesh.

#### Сравнение Cloudflare Tunnel vs NetBird

| Критерий | Cloudflare Tunnel | NetBird |
| --- | --- | --- |
| Протокол | HTTPS-туннель | WireGuard (ChaCha20) |
| Адресация | DNS `*.example.com` → VPS | Приватные IP 100.64/12 |
| Открытые порты | 0 | 0 |
| Latency | Через edge Cloudflare | Прямой peer-to-peer |
| Скорость настройки | Быстро | Больше движущихся частей |
| Цена | Free tier | Self-host = ещё 1 VPS (~300 ₽/мес) |
