## Почему решения такие

- **Не создавал отдельные тематические подпапки** (`wiki/Cursor/`, `wiki/Claude-Code/` и т. п.) — нет источников. Создам, когда появятся.

- **Все wiki-страницы на русском**, английский — только в терминах, командах, точечных цитатах.
- **Stub-страницу `wiki/entities/openclaw`** оставил явно, чтобы не потерять упоминание в кейсе, но с честной пометкой «источника пока нет».
- **`raw/` не трогал** вообще — ни один файл не модифицирован, никуда не перемещён.

## Что стоит обработать следующим приоритетом

1. **Notion-материалы** (`raw/Telegram/Промт установки «Второго мозга»`) — только внешние ссылки, не могу прочитать. Нужен локальный экспорт (PDF / Markdown / HTML).
2. **Cursor и Windsurf** — нужны первые источники, чтобы закрыть пробелы в AI IDE.
3. **Темы «SaaS с ИИ», «Ниши», «Монетизация»** — нужны первые источники, чтобы заводить подпапки.
4. **Собственные кейсы вайбкодинга** — без них база останется «теоретической».
5. **OpenClaw** — либо найти полноценный источник, либо удалить stub-страницу.
6. **SQL / Docker / S3-шпаргалки** — переводить в concept-страницы только когда появится связный материал по применению в AI-агентских стеках.

## Блокер

Не могу обработать `raw/Telegram/Промт установки «Второго мозга» - 20260829022008922.md` — файл содержит только ссылки на Notion, которые AI-агенту недоступны. Чтобы wiki-страницы по этим материалам появились, нужен локальный экспорт страниц Notion (Markdown / PDF / HTML). Варианты:

1. В Notion откройте страницу → `⋯` → `Export` → Markdown & CSV → пришлите `.md` или `.zip`.
2. Либо скопируйте содержимое страницы вручную в `.md` и положите в `raw/`.
