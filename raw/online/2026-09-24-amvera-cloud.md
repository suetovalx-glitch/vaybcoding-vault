## Ключевые тезисы (кратко)

- Российская PaaS-платформа, основана в 2023.
- Деплой через `git push amvera master` одной командой.
- Регионы: Москва + Варшава.
- 6 тарифов: 170 ₽ — 7 750 ₽/мес.
- Поминутная тарификация, списание раз в час.
- Managed СУБД от 290 ₽/мес.
- LLM API (GPT 5, LLaMA), бесплатное проксирование OpenAI/Claude/Gemini.
- AI-IDE Polide (собственная альтернатива Cursor).
- Стартовый бонус 111 ₽.

## Ключевые цитаты

> Amvera Cloud — облако для простого развертывания и обновления IT-проектов. Деплой через GitOps, доставка кода через push в Git-репозиторий с использованием всего одного конфигурационного файла.

> Оплата идет с поминутной тарификацией только за запущенные контейнеры. Вы платите только за ресурс, потребляемый Вашим приложением.

> Если ваш сервис пытается обратиться к API OpenAI (или к Claude от Anthropic), трафик будет автоматически перенаправлен через иностранный IP-адрес. Это бесплатно и не требует никакой настройки.

> Международный кластер в Варшаве позволит пользователям успешно запускать свой код не беспокоясь о возможных географических ограничениях сервисов.
