## Навигация и файлы

- `ls -la` — полный список файлов (включая скрытые) с правами и датами.
- `pwd` — показать текущий путь.
- `cd /path` — перейти в директорию; `cd ..` — на уровень выше; `cd ~` — в домашнюю папку.
- `mkdir dir` — создать папку.
- `rm file` / `rm -rf dir` — удалить файл/папку (осторожно с `-rf`).
- `cp src dest` / `cp -R src dest` — скопировать файл/папку.
- `mv src dest` — переместить или переименовать.
- `touch file.txt` — создать пустой файл.
- `cat file.txt` / `less file.txt` — просмотреть содержимое (для больших файлов лучше `less`).

---

## Дисковая подсистема и место

- `df -h` — свободное место на дисках (человекочитаемо).
- `du -sh /path` — размер папки.
- `du -ah --max-depth=1 /path | sort -h` — размеры подпапок, удобно для поиска «тяжелых» директорий (актуально при бэкапах и очистке).

---

## Процессы, нагрузка, память

- `top` — живая нагрузка (CPU/RAM), сортировка по потреблению.
- `htop` — более удобный аналог `top` (если установлен).
- `free -h` — использование оперативной памяти.
- `ps aux` — список всех процессов.
- `kill PID` / `kill -9 PID` — завершить процесс (лучше сначала без `-9`).
- `uptime` — время работы сервера и средняя нагрузка (load average).

Это прямо связано с твоей задачей диагностики производительности VPS: по `top/htop`, `free`, `df` быстро видно узкие места.

## Сеть

- `ping example.com` — проверить доступность хоста.
- `curl -I https://example.com` — получить HTTP-заголовки (полезно для проверки сайта).
- `ss -tulpn` — показать открытые порты и процессы (современная замена `netstat`).
- `wget url` / `curl -O url` — скачать файл.

---

## Управление службами (systemd)

- `systemctl status service` — статус службы (например, `nginx`, `docker`).
- `systemctl start/stop/restart service` — запустить/остановить/перезапустить.
- `systemctl enable/disable service` — включить/выключить автозапуск.

Учитывая твой интерес к контейнерам и Proxmox — часто нужно перезапускать Docker/Podman-сервисы и проверять их статус.

## Пакеты и обновления

Для Debian/Ubuntu:

- `apt update` — обновить списки пакетов.
- `apt upgrade` — обновить пакеты.
- `apt install pkg` — установить пакет.
- `apt remove pkg` — удалить пакет (конфиги остаются).
- `apt purge pkg` — полное удаление с конфигами.

Для CentOS/Rocky/AlmaLinux:

- `dnf update` / `dnf upgrade`
- `dnf install pkg`

## Логи

- `journalctl -u service -n 50` — последние 50 строк логов службы.
- `journalctl -u service -f` — логи в реальном времени (аналог `tail -f`).
- `tail -n 100 /var/log/syslog` или `/var/log/messages` — последние строки системного лога.

Полезно при отладке после деплоя, бэкапов, настройки сервисов.

## SSH и безопасность

- `ssh user@host` — подключиться по SSH.
- `ssh-keygen` — сгенерировать SSH-ключ (ты уже интересовался этим для Windows).
- `scp file user@host:/path` — скопировать файл по SSH.

## Работа с архивами (бэкапы)

Учитывая твои задачи по бэкапу сайта:

- `tar czf backup.tar.gz /path/to/site` — создать сжатый архив.
- `tar xzf backup.tar.gz` — распаковать архив.
- `zip -r archive.zip folder/` — создать ZIP-архив.
- `unzip archive.zip` — распаковать ZIP.

## Контейнеры (Docker / Podman)

Ты просил шпаргалки по Docker и Podman, вот базовые команды, которые чаще всего нужны на VPS:

- `docker ps` / `podman ps` — список запущенных контейнеров.
- `docker ps -a` / `podman ps -a` — все контейнеры (включая остановленные).
- `docker start/stop/restart container` / аналогично для Podman.
- `docker logs -f container` / `podman logs -f container` — логи контейнера в реальном времени.
- `docker exec -it container bash` / `podman exec -it container bash` — войти в контейнер.
- `docker pull image` / `podman pull image` — скачать образ.

- `glances` — компактный мониторинг CPU/RAM/диска/сети (если установлен).
- `netdata` — веб-панель метрик (если развернут на VPS).

## Частые связки, которые удобно держать под рукой

- Быстро найти большие файлы: `find / -type f -size +100M -exec ls -lh {} \; 2>/dev/null`
- Посмотреть, кто сколько ест CPU: `ps -eo pid,user,state,comm,pcpu --sort=-pcpu | head`
- Проверить, не забился ли диск: `df -h && du -sh /var/www /home 2>/dev/null`

## Для автоматизации и скриптов (бэкапы, метрики)

- `rsync -av --delete src dest` — синхронизация файлов (ты просил шпаргалку по rsync).
- `cron` — планировщик задач; `crontab -e` — редактировать задачи текущего пользователя.
- `bash script.sh` — запуск скрипта.

Эти команды идеально ложатся на твои скрипты для бэкапа сайта и проверки метрик.
