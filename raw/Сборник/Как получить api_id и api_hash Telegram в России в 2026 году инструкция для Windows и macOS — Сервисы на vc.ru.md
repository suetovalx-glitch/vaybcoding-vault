Актуально на 15 июля 2026 года.

При попытке создать приложение на сайте Telegram многие пользователи из России сталкиваются с замкнутым кругом:

- без VPN сайт my.telegram.org не открывается;
- с VPN сайт открывается, код авторизации приходит;
- после заполнения формы появляется ERROR или \[object Object\];
- смена браузера, режима инкогнито и названия приложения не помогает.

Такие ошибки действительно массово встречаются у пользователей. В официальном баг-трекере Telegram также есть сообщения о невозможности создать API-приложение с ошибками ERROR и \[object Object\].

## Почему возникает ошибка

Точная причина Telegram официально не раскрывается. Однако по опыту пользователей проблема может возникать из-за несовпадения региона номера телефона и IP-адреса.

Например:

- Telegram-аккаунт зарегистрирован на российский номер +7;
- пользователь заходит через VPN с IP Нидерландов, Германии или США;
- Telegram не позволяет создать приложение и показывает общую ошибку без объяснения.

При этом на части российских провайдеров доступ к my.telegram.org ограничивается через DNS. Это можно обойти без VPN, указав IP-адрес сайта напрямую в системном файле hosts. Такой способ описан пользователями как рабочий в июне–июле 2026 года.

## Важное условие

Перед началом:

1. Полностью отключите VPN.
2. Отключите прокси в браузере и системе.
3. Используйте обычный российский интернет: домашний или мобильный.
4. Убедитесь, что Telegram-аккаунт зарегистрирован на российский номер.

Нам нужно сохранить российский IP, но заставить сайт my.telegram.org открываться без обращения к DNS-серверу провайдера.

## Инструкция для Windows 10 и Windows 11

## Шаг 1. Откройте Блокнот от имени администратора

Нажмите кнопку «Пуск» и введите:

Блокнот

Нажмите на приложение правой кнопкой мыши и выберите:

Запуск от имени администратора

Подтвердите запуск.

## Шаг 2. Откройте файл hosts

В Блокноте нажмите:

Файл → Открыть

Перейдите в папку:

C:\\Windows\\System32\\drivers\\etc

По умолчанию Блокнот показывает только текстовые документы. В правом нижнем углу измените тип файлов:

Текстовые документы (\*.txt)

на:

Все файлы (\*.\*)

После этого откройте файл:

hosts

## Шаг 3. Добавьте адрес Telegram

В самом конце файла добавьте новую строку:

149.154.167.220 my.telegram.org

Между IP-адресом и доменом должен быть пробел.

Сохраните файл сочетанием:

Ctrl + S

### Если файл не сохраняется

Значит, Блокнот был запущен без прав администратора. Закройте его и снова выполните первый шаг.

Также проверьте, что файл не сохранился под названием:

hosts.txt

Файл должен называться просто:

hosts

без расширения.

## Шаг 4. Очистите DNS-кэш

Откройте меню «Пуск», найдите:

Командная строка

Запустите её от имени администратора и выполните:

ipconfig /flushdns

Должно появиться сообщение об успешной очистке кэша сопоставителя DNS.

## Шаг 5. Полностью перезапустите браузер

Закройте не только вкладку, но и весь браузер.

Для надёжности можно открыть «Диспетчер задач» сочетанием:

Ctrl + Shift + Esc

и убедиться, что процессы Chrome, Edge, Firefox или другого браузера завершены.

После этого снова откройте браузер.

## Шаг 6. Создайте Telegram API

Откройте:

https://my.telegram.org

Введите номер телефона в международном формате:

+7XXXXXXXXXX

Код авторизации обычно приходит сообщением в приложение Telegram, а не по SMS.

После входа выберите:

API development tools

Пример заполнения формы:

App title: PersonalClientApp Short name: personalclient26 URL: оставить пустым Platform: Desktop Description: Personal client application for working with Telegram data.

Рекомендации:

- используйте только английские буквы и цифры;
- не используйте кириллицу;
- в Short name не ставьте пробелы;
- не пишите в названии слово Telegram;
- выберите платформу Desktop.

Нажмите кнопку создания приложения.

После успешной регистрации появятся:

App api\_id App api\_hash

Сохраните их в безопасном месте.

## Инструкция для macOS

## Шаг 1. Откройте Терминал

Откройте поиск Spotlight:

Command + Space

Введите:

Терминал

и запустите приложение.

## Шаг 2. Откройте файл hosts

Введите команду:

sudo nano /etc/hosts

Нажмите Enter.

macOS попросит пароль пользователя. Во время ввода пароля символы на экране не отображаются — это нормально. Введите пароль и нажмите Enter.

## Шаг 3. Добавьте адрес Telegram

Перейдите в конец файла с помощью стрелок на клавиатуре и добавьте строку:

149.154.167.220 my.telegram.org

Сохраните файл:

Control + O

Нажмите Enter для подтверждения имени файла.

Закройте редактор:

Control + X

Обратите внимание: используется именно клавиша Control, а не Command.

## Шаг 4. Очистите DNS-кэш macOS

Поочерёдно выполните две команды:

sudo dscacheutil -flushcache sudo killall -HUP mDNSResponder

Если после выполнения второй команды ничего не появилось, это нормально.

## Шаг 5. Полностью закройте браузер

На macOS недостаточно закрыть окно браузера красной кнопкой.

Полностью завершите его сочетанием:

Command + Q

После этого снова запустите браузер.

## Шаг 6. Создайте приложение

Откройте:

https://my.telegram.org

Авторизуйтесь по номеру телефона, перейдите в раздел:

API development tools

и заполните форму.

Пример:

App title: PersonalClientApp Short name: personalclient26 URL: оставить пустым Platform: Desktop Description: Personal client application for working with Telegram data.

После создания приложения вы получите:

api\_id api\_hash

Официальная документация Telegram подтверждает, что именно через раздел API development tools выдаются api\_id и api\_hash. В настоящий момент к одному номеру телефона может быть привязан только один api\_id.

## Обязательно удалите строку из hosts

После того как api\_id и api\_hash получены, рекомендуется вернуть файл hosts в исходное состояние.

IP-адрес Telegram может измениться. Если оставить старый адрес навсегда, в будущем сайт может перестать открываться.

## Windows

Снова откройте Блокнот от имени администратора и файл:

C:\\Windows\\System32\\drivers\\etc\\hosts

Удалите строку:

149.154.167.220 my.telegram.org

Сохраните файл и выполните:

ipconfig /flushdns

## macOS

Откройте файл:

sudo nano /etc/hosts

Удалите строку:

149.154.167.220 my.telegram.org

Сохраните изменения и выполните:

sudo dscacheutil -flushcache sudo killall -HUP mDNSResponder

## Что делать, если ошибка осталась

## 1\. Проверьте VPN

VPN должен быть полностью отключён. Проверьте:

- отдельную программу VPN;
- VPN-расширение в браузере;
- системный прокси;
- GoodbyeDPI, Zapret, Hiddify и аналогичные программы;
- функцию защищённого соединения в антивирусе.

## 2\. Перезапустите компьютер

Иногда браузер или система продолжают использовать старый DNS-кэш даже после команды очистки.

## 3\. Попробуйте другой российский интернет

Например:

- раздайте мобильный интернет с телефона;
- попробуйте другого оператора;
- переключитесь с домашнего интернета на мобильный.

Строка в hosts при этом должна оставаться активной.

## 4\. Проверьте, не создавали ли вы приложение раньше

Telegram разрешает привязать к одному номеру только один api\_id. Если приложение уже создавалось, после открытия API development tools могут сразу отображаться старые данные.

## 5\. Обновите страницу после ошибки

Иногда форма показывает ошибку, но приложение фактически создаётся. Обновите страницу и снова откройте API development tools.

## 6\. Попробуйте простое название

Не используйте в названии слова:

Telegram Parser Scraper Mass Sender Spam

Можно указать нейтральное название:

PersonalClientApp

## Важное предупреждение о безопасности

Никому не отправляйте:

- api\_hash;
- пароль двухэтапной аутентификации;
- файл сессии Telethon или Pyrogram;
- строку сессии;
- код авторизации из Telegram.

Сам по себе api\_id не является полноценным паролем, но api\_hash и особенно активная сессия должны храниться в секрете.

Не вставляйте их в публичный GitHub-репозиторий и не публикуйте на форумах.

Также Telegram предупреждает, что использование API для спама, массовых нежелательных сообщений, накрутки просмотров или подписчиков может привести к постоянной блокировке аккаунта.

## Краткая версия решения

1. Отключить VPN.
2. Добавить в файл hosts строку:

149.154.167.220 my.telegram.org

1. Очистить DNS-кэш.
2. Полностью перезапустить браузер.
3. Открыть my.telegram.org.
4. Создать приложение и получить api\_id и api\_hash.
5. Удалить добавленную строку из hosts.
6. Ещё раз очистить DNS-кэш.

Способ является пользовательским обходным решением, а не официальной рекомендацией Telegram. Он работает на момент публикации, но в будущем IP-адрес или механизм ограничения доступа может измениться.
