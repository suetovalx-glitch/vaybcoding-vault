## То, что уже использую

- Calendar: справа календарь висит виджетом и можно легко провалиться в заметки нужного дня.
- cMenu: удобное меню для редактирования текста. Чтобы не писать руками звездочки и дефисы для стилизации.
- Iconize: можно каждой заметки поставить иконку.
- Kanban: Пользуюсь и доволен.
- Meld Encrypt: Шифрование заметок.
- Outliner: Удобная работа с маркированными списками.
- Obsidian LiveSync

## Плагины, которые я хочу попробовать

- Checklist: Собирает все чеклисты по всем заметкам в одном месте. Удобно, чтобы быть в курсе того, что надо сделать и не бегать по всем заметкам для этой цели
- Dataview: Мощный инструмент для построения баз данных из заметок. Пойдет для тех, кто строил из Notion мощные базы данных с фильтрами.
- Excalidraw: Рисовалка диаграм.
- Multi Properties: Массовое добавления свойств заметок. Из коробки можно свойства добавлять по одной странице
- Omnisearch: Мощный поиск. Может даже искать по содержимым файлов (извлекает текст из картинок)
- Templater: Что-то мощное для шаблонизации. Даже можно на JS расширения писать. Доберусь до него когда-то
- DB Folder: Делает из существующей папки базу данных. Очень удобная штука для конвертации больших папок во что-то системное

## То, что порекомендовали в комментах, но пока решил не ставить

- Beautitab: При открытии новой вкладки в обсидиане показывает красивую страницу, где можно посмотреть последние вкладки и тд. Я открываю заметки напрямую и пустую вкладку не вижу.
- Highlightr: Подчеркивает текст в заметках. Пока не очень познал смысл визуального выделения контента.
- Language Translator: Переводит текст на нужный язык.
- Projects: Мощный плагин для ведения проектов.
- Remotely Save: еще один способ синхронизации заметок.
- Soundscapes: Плеер для фоновой музыки.
- Style Settings: Еще один плагин для визуала.
- Advanced Tables: Мощные таблицы.
- Git. Синк через гит.
- QuickAdd: Макросы для управления контентом.
- Periodic Notes: Заметки на день/месяц/неделю.
- Advanced Slides: Делать презы из Markdown.
- Admonition: Еще один визуальный плагин для выделения текста в визуальные блоки
- Buttons: Кнопки для запуска действий.
- Banners: Из Notion фича с добавлением поверх заметки большого баннера.
- Excalibrain: Построение майндмапов из заметок.
- Leaflet: Встраивание карт в заметки.
- Dice Roller: Сбрасывание кубиков.
- Tab Switcher: Переключение табов через ctrl+tab на предыдущий используемый, а не "влево-вправо".
- Vault Statistic: Отображение количества заметок и тд.
- Show Current File Path: Плагин для отображения пути до файла текущей заметки
- Copilot + Openrouter: ИИ внутри обси
