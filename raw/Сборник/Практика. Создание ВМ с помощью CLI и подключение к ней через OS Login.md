## Установка Yandex Cloud CLI

1️⃣ Установите Yandex Cloud CLI на ваш компьютер. Для этого следуйте [инструкции по установке](https://yandex.cloud/ru/docs/cli/quickstart#install) в документации. Yandex Cloud CLI поддерживает основные операционные системы: Windows, macOS и Linux.

2️⃣ После завершения установки убедитесь, что CLI корректно установился. Выполните команду `yc --version`, которая должна вывести установленную версию:

BASH

```bash
yc --version
```

```markdown
Yandex Cloud CLI 0.132.1 darwin/arm64
```

💡 Если вы используете macOS или Linux, настройте автодополнение для команд в соответствии с той же [инструкцией по установке](https://yandex.cloud/ru/docs/cli/quickstart#install), чтобы ускорить работу в терминале. Автодополнение можно вызывать кнопкой TAB.

3️⃣ Аутентифицируйтесь в Yandex Cloud и настройте профиль по [инструкции](https://yandex.cloud/ru/docs/cli/quickstart#initialize). Профиль — это облако и каталог, в котором будут выполняться команды. Вы можете создать несколько профилей и переключаться между ними, как если бы вы переключались между облаками и каталогами в web UI. Также в профиле можно указать зону доступности по умолчанию для сервиса Compute Cloud (пункт 8 в инструкции).

## Создание ВМ

Теперь, когда CLI настроен, создайте прерываемую ВМ c доступом по OS Login.

1️⃣ Выполните команду для создания ВМ:

BASH

```bash
yc compute instance create \
  --name my-vm \
  --zone ru-central1-a \
  --public-ip \
  --preemptible \
  --memory 2 \
  --cores 2 \
  --create-boot-disk image-id=fd84uoseqemi8gihbs05,size=10 \
  --metadata enable-oslogin=true
```

В команде используются флаги:

- `--name` — имя ВМ.
- `--zone` — зона доступности.
- `--public-ip` — назначить публичный IP-адрес виртуальной машине.
- `--preemptible` — сделать ВМ прерываемой.
- `--memory` — количество ГБ RAM.
- `--cores` — количество vCPU.
- `--create-boot-disk` — параметры для загрузочного диска в формате ключ-значение:
	- ` image-id` — ID образа. Найти нужный ID можно в [Yandex Cloud Marketplace](https://yandex.cloud/ru/marketplace). В примере это образ Ubuntu 24.04.
	![](https://pictures.s3.yandex.net/resources/image_39_1739886618.png)
	- `size` — размер диска в ГБ.
- `--metadata enable-oslogin=true` — флаг для включения доступа по OS Login.

## Подключение и установка утилит

Теперь нужно подключиться к ВМ с помощью OS Login. Напомним, что OS Login позволяет подключаться к ВМ через пользователей и сервисные аккаунты в сервисе IAM. Так как вы уже аутентифицировались в CLI, осталось только подключиться.

BASH

```bash
yc compute ssh --name <имя_вм>
```

Вместо имени для подключения можно использовать ID виртуальной машины во флаге `--id`.

💻 Если вы получаете ошибку `Connection refused`, подождите несколько секунд, и SSH станет доступен.

После успешного подключения к ВМ установите утилиту stress — она пригодится в дальнейшей практике:

1️⃣ Обновите локальный индекс пакетов.

BASH

```bash
sudo apt update
```

2️⃣ Обновите систему.

BASH

```bash
sudo apt upgrade
```

3️⃣ Установите утилиту stress.

BASH

```bash
sudo apt install stress
```

4️⃣ Проверьте, что утилита установлена, с помощью `stress --version`.

BASH

```bash
stress --version
```

```markdown
stress 1.0.7
```

💡 Выключите, но не удаляйте созданную ВМ, она понадобится для следующих практических работ.

## Что важно запомнить из этого урока

- Для работы с Yandex Cloud CLI необходимо установить утилиту yc, а также настроить профиль.
- Получить доступ к ВМ через OS Login можно с помощью команд `yc compute ssh --name <имя_вм>` или `yc compute ssh --id <ID_вм>`.

❗️ Не забудьте остановить ресурсы, чтобы избежать лишних трат.
