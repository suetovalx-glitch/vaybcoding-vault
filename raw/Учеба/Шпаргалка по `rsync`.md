## Шпаргалка по `rsync`: изучаем утилиту для синхронизации файлов

`rsync` — это инструмент командной строки для копирования и синхронизации файлов локально и по сети. Главная фишка: он передаёт только изменения (дельты), а не весь файл целиком, и умеет сохранять права, владельцев, временные метки и ссылки.

---

## Установка

- **Ubuntu/Debian**: `sudo apt update && sudo apt install rsync`
- **CentOS/RHEL/Fedora**: `sudo yum install rsync` или `sudo dnf install rsync`
- **macOS**: часто уже есть; если нет — через Homebrew: `brew install rsync` (у тебя как раз был запрос про Homebrew раньше).
- Проверка: `rsync --version`

---

## Базовый синтаксис

bash

```bash
rsync [опции] <источник> <приёмник>
```

Источник и приёмник могут быть:

- локальными путями: `/home/user/docs/` `/backup/docs/`
- удалёнными через SSH: `user@host:/remote/path`
- через протокол rsync-демона: `rsync://host/module`

---

## Самые полезные опции

|Опция|Значение|
|---|---|
|`-a` / `--archive`|«Архивный режим»: рекурсивно, сохраняет права, ссылки, даты, владельцев и т.д. Почти всегда нужна.|
|`-v` / `--verbose`|Подробный вывод (что копируется).|
|`-h` / `--human-readable`|Размеры файлов в понятном виде (K, M, G).|
|`-z` / `--compress`|Сжимать данные при передаче (полезно по сети).|
|`--progress`|Показывать прогресс копирования.|
|`--delete`|Удалять в приёмнике файлы, которых нет в источнике (осторожно!).|
|`--exclude=ШАБЛОН`|Исключить файлы/папки по шаблону.|
|`--include=ШАБЛОН`|Включить только указанные файлы/папки.|
|`--dry-run`|Пробный запуск: покажет, что будет сделано, без реального копирования.|
|`-e ssh`|Использовать SSH как транспорт (по умолчанию при удалённой работе).|
|`--bwlimit=KBPS`|Ограничить скорость передачи (в КБ/с).|

---

## Частые сценарии

### Локальная синхронизация (бэкап папки)

bash

```bash
rsync -avh --progress /home/user/documents/ /backup/documents/
```

### Синхронизация на удалённый сервер по SSH

bash

```bash
rsync -avzh --progress /local/path/ user@server:/remote/path/
```

### Загрузка с удалённого сервера на локальный

bash

```bash
rsync -avzh --progress user@server:/remote/path/ /local/path/
```

### Исключить временные файлы и логи

bash

```bash
rsync -avh --exclude='*.tmp' --exclude='*.log' /src/ /dest/
```

Можно вынести исключения в файл:

bash

```bash
rsync -avh --files-from=list.txt /src/ /dest/
```

где `list.txt` содержит пути или шаблоны.

### Инкрементный бэкап с сохранением старых версий

bash

```bash
rsync -avh --backup --backup-dir=/backup/old_versions /src/ /backup/current/
```

### Ограничить скорость (чтобы не забивать канал)

bash

```bash
rsync -avzh --bwlimit=5000 /src/ user@server:/dest/
```

(5000 КБ/с ≈ 40 Мбит/с)

### Пробный запуск (безопасно проверить, что произойдёт)

bash

```bash
rsync -avn --delete /src/ /dest/
```

Флаг `-n` — то же, что `--dry-run`.

---

## Важные нюансы и «подводные камни»

- **Косая черта в конце пути имеет значение**:
    - `/src/` — копируется содержимое папки `src`.
    - `/src` — копируется сама папка `src` внутрь приёмника.
- **`--delete` опасен**: если ошибиться с источником/приёмником, можно случайно удалить файлы. Всегда сначала тестируй с `--dry-run`.
- **Права и владельцы**: `-a` сохраняет их, но на приёмнике нужны соответствующие права (особенно при смене пользователя).
- **Символические ссылки**: по умолчанию копируются как ссылки. Если нужно развернуть их в файлы, используй `-L`.

## Связь с твоими предыдущими задачами

Учитывая, что ты работал с VPS, Obsidian, синхронизацией и автоматизацией:

- `rsync` отлично подходит для **регулярной синхронизации данных между VPS и локальной машиной** (например, бэкапы баз, конфигов, файлов сайта).
- Можно **встроить в скрипт** для автоматизации (как ты делал для проверки метрик и синхронизации Obsidian).
- Для **безопасной передачи** используй SSH-ключи (ты спрашивал про генерацию SSH-ключа на Windows) — `rsync` будет работать без ввода пароля.
- Если хочешь **ограничить нагрузку на VPS**, используй `--bwlimit`, чтобы не «положить» канал при больших передачах.

Пример простого скрипта-бэкапа на VPS:

bash

```bash
#!/usr/bin/env bash
SOURCE="/var/www/html"
DEST="user@vps-ip:/backup/www"
rsync -avzh --delete --progress --exclude='cache/' "$SOURCE" "$DEST"
```

## План изучения rsync (по шагам)

1. **Поставить rsync** на своей системе (локально или на VPS).
2. **Потренироваться локально**: синхронизировать пару папок, попробовать с `-n` и `--delete`.
3. **Подключить SSH-ключ** и попробовать rsync между локальной машиной и VPS.
4. **Добавить исключения** (`--exclude`) и проверить, как это работает.
5. **Сделать пробный бэкап** важной папки с `--backup` и посмотреть результат.
6. **Написать маленький скрипт** с rsync и запустить его вручную.
7. **Настроить cron** (планировщик) для автоматического запуска (если актуально).
