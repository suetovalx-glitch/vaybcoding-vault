## Шпаргалка по Git

**Базовые команды:**

- `git init` — создать репозиторий.
- `git clone <url>` — клонировать репозиторий.
- `git status` — показать статус файлов.
- `git add <file>` или `git add .` — добавить файлы в индекс.
- `git commit -m "сообщение"` — зафиксировать изменения.
- `git log` — история коммитов.
- `git branch` — список веток; `git branch <name>` — создать ветку; `git checkout <name>` или `git switch <name>` — переключиться.
- `git merge <branch>` — слить ветку.
- `git push` / `git pull` — отправить/получить изменения.

**Частые сценарии:**

- Исправить последний коммит: `git commit --amend`.
- Отменить изменения в файле: `git checkout -- <file>` (старый стиль) или `git restore <file>`.
- Откатить коммит: `git revert <hash>` (безопаснее) или `git reset --hard <hash>` (осторожно).

## Шпаргалка по Docker

**Основные команды:**

- `docker pull <image>` — скачать образ.
- `docker run <image>` — запустить контейнер.
- `docker ps` — список запущенных контейнеров; `docker ps -a` — все.
- `docker stop <container>` / `docker start <container>` — остановить/запустить.
- `docker rm <container>` — удалить контейнер; `docker rmi <image>` — удалить образ.
- `docker exec -it <container> sh` — войти в контейнер.

**Работа с Dockerfile:**

- `FROM` — базовый образ.
- `WORKDIR` — рабочая директория.
- `COPY` / `ADD` — скопировать файлы.
- `RUN` — выполнить команду при сборке.
- `CMD` — команда по умолчанию при запуске.

**Docker Compose:**

- `docker compose up` — запустить сервисы.
- `docker compose down` — остановить и удалить.
- Конфигурация в `docker-compose.yml`.

## Шпаргалка по WSL (Windows Subsystem for Linux)

**Полезные команды:**

- `wsl --list --verbose` — список дистрибутивов и их статус.
- `wsl --set-default <distro>` — установить дистрибутив по умолчанию.
- `wsl --shutdown` — полностью остановить все экземпляры WSL.
- `wsl -d <distro> -e <command>` — выполнить команду в конкретном дистрибутиве.
- Доступ к файлам Windows из WSL: `/mnt/c/...`.
- Доступ к WSL из Windows: `\\wsl$\<distro>\...`.

**Частые задачи:**

- Установить дистрибутив: в Microsoft Store или `wsl --install -d <name>`.
- Обновить ядро WSL: `wsl --update`.

## Шпаргалка по Podman

Podman — аналог Docker без демона, совместим по CLI.

**Ключевые команды:**

- `podman pull <image>` — скачать образ.
- `podman run <image>` — запустить контейнер.
- `podman ps` / `podman ps -a` — список контейнеров.
- `podman stop <container>` / `podman start <container>`.
- `podman rm <container>` / `podman rmi <image>`.
- `podman exec -it <container> /bin/sh` — войти в контейнер.

**Отличия от Docker:**

- Не нужен демон: команды выполняются напрямую.
- Часто используется с rootless-режимом (без sudo).
- Совместим с Docker Compose через `podman compose`.
