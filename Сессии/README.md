# Сессии

Папка для **памяти агента** — сохранённых диалогов с AI-ассистентом, чтобы в следующих сессиях контекст не терялся.

## Что это

LLM (MiniMax-M3 в pi-coding-agent) **не помнит** между сессиями. Каждый новый чат — как первая встреча. Чтобы это обойти:

1. **В конце каждой сессии** ассистент сохраняет диалог в `Сессии/YYYY-MM-DD/диалог-NN-тема.md`.
2. **В начале новой сессии** ассистент читает `Сессии/YYYY-MM-DD/_summary.md` (или последний) и подгружает в контекст как «память».
3. **Поиск** по старым сессиям: `rg "тема" Сессии/` или открыть `Сессии/index.md`.

## Структура

```
Сессии/
├── README.md                              # этот файл
├── index.md                                # общая навигация
├── _templates/
│   └── session-template.md                 # шаблон новой сессии
├── 2026-09-24/
│   ├── диалог-01-переезд-vps.md
│   ├── диалог-02-план-агента.md
│   ├── ...
│   └── _summary.md                         # конспект дня (= память)
└── 2026-09-25/
    └── ...
```

## Как использовать

### Начало новой сессии

Скажи ассистенту:

> «Прочитай `Сессии/` и напомни, на чём мы остановились»

или конкретнее:

> «Что было в последнем summary?»

Ассистент прочитает последний `_summary.md` и подхватит контекст.

### Конец сессии

Скажи:

> «Сохрани сессию»

или

> «Зафиксируй, что мы сделали»

Ассистент создаст файл в `Сессии/YYYY-MM-DD/` по шаблону.

### Поиск по старому

- `rg -i "adminvps" Сессии/` — найти все упоминания.
- `read Сессии/index.md` — общая навигация.

## Что НЕ хранить здесь

- **Секреты** (API-ключи, токены) — никогда, только в `~/.config/pi/secrets.env` с правами 600.
- **Очень личное** (если vault станет публичным или будет расшарен) — вынести в `*-private.md` и добавить в `.gitignore`.
- **Бинарные файлы** — текст и markdown, никаких вложений.

## Автоматизация (когда переедем на VPS)

Сейчас — вручную. На VPS добавим:

- Хук после каждой сессии → автосохранение в `Сессии/YYYY-MM-DD/`.
- Cron раз в сутки → генерация `_summary.md` (через короткую LLM-сессию «суммаризируй»).
- Pre-session hook → автоподгрузка последнего `_summary.md` в системный промпт.

Подробнее — в `wiki/concepts/agent-memory.md` (создать, когда переедем).
