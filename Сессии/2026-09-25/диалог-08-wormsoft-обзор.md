# Сессия 08: Обзор провайдера Wormsoft AI

**Дата:** 2026-09-25
**Время:** ~00:30
**Ассистент:** MiniMax-M3
**Канал:** pi-coding-agent CLI (chat)

## Контекст

Пользователь попросил: «посмотри провайдера <https://ai.wormsoft.ru/> выбери модели чтоб использовать». Задача — изучить провайдера Wormsoft AI и предложить выбор моделей для использования в агенте.

Из предыдущих сессий:

- Агент pi-coding-agent поддерживает OpenAI-совместимые провайдеры.
- Сейчас мы выбираем LLM-провайдера для агента, который будет жить на VPS (Финляндия).
- VPS в Финляндии — вопрос с доступом к LLM-API из РФ не критичен, но Wormsoft заявляет работу без VPN — это плюс на переходный период.

## Что обсудили

- **Главный факт:** каталог моделей на Wormsoft доступен **только через авторизованный запрос** к `/api/gpt/models`. Без API-ключа страницы `/models` и `/docs/llm/models` показывают пустую таблицу (контент грузится через JS).
- **Подтверждено через `curl`:** эндпоинт `/api/gpt/models` отвечает `401 Unauthorized` с любым левым Bearer-токеном.
- **API:** совместим с OpenAI Responses API, есть алиасы `/gpt/v1`, `/gpt/v1/v1`.
- **Серверная часть:** nginx/1.29.7 + Express (Node.js). Классическая связка для агрегатора.
- **Подписки:** 5 тарифов от бесплатного (0 ₽/мес, 5 000 кредитов / 20 ч / 1 запрос/мин) до 8 000 ₽/мес. Названия платных тарифов скрыты в дизайне главной страницы.
- **Кредитная система:** отдельно от rate limit. Кредиты списываются по факту использования, rate limit — независимое ограничение скорости.
- **Из чужих отзывов** (обсуждение на fediverse про Roo Code) нашли подтверждённую модель: `wormsoft/code/low` — собственная алиасная модель Wormsoft для кода, бесплатная.
- **Из доки** нашли формат имён моделей `префикс/модель` (как у OpenRouter), например `openai/gpt-5.4` — но это синтетический пример, не реальная доступная модель.
- **Догадка по конвенции агрегаторов:** у Wormsoft, скорее всего, есть OpenAI, Anthropic, Google, DeepSeek, Meta/Llama и собственные алиасы. Но это гипотеза — без ключа не проверить.

## Принятые решения

- **Без API-ключа я не могу рекомендовать конкретные ID моделей.** Любой список будет догадкой, а не фактом. Это зафиксировано в обзоре как блокер.
- **Wormsoft подходит как один из провайдеров**, но не единственный — для отказоустойчивости в `~/.config/pi/config.json` нужно настроить fallback на OpenRouter / прямой OpenAI / прямой Anthropic.
- **Следующий шаг — получить API-ключ** через `@WormsoftBot`. Начать с бесплатного (5 000 кредитов) для теста, потом перейти на тариф за 1 000 ₽/мес для серьёзной работы.
- **После ключа** — выполнить две команды:
  1. `curl /api/gpt/models` → получить список.
  2. `curl /pricing` или зайти на `/docs/llm/pricing-and-usage` авторизованным.
- **Только после реального списка** — выбрать 3–4 модели (default / cheap / code / vision) и прописать в `~/.config/pi/config.json`.

## Технические детали

- API полностью OpenAI-совместимый — `base_url = "https://ai.wormsoft.ru/api/gpt"` (или `/gpt/v1`).
- Формат имён моделей: `<провайдер>/<модель>` — стандарт OpenRouter-конвенции.
- Подтверждённая алиас-модель: `wormsoft/code/low` — собственная Wormsoft для кода, бесплатная.
- 5 тарифов: 0 ₽ / 1 000 ₽ / 2 000 ₽ / 4 000 ₽ / 8 000 ₽ за месяц.
- Самый дешёвый платный (1 000 ₽) даёт 150 000 кредитов / 8 ч / 15 запросов в минуту — разумный минимум для агента.
- Проверка `curl -i "https://ai.wormsoft.ru/api/gpt/models" -H "Authorization: Bearer probe"` вернула `HTTP/1.1 401 Unauthorized` с телом `{"statusCode":401,"message":"Unauthorized",...}`.
- Сервер: nginx/1.29.7 + Express. Контакт для ключа: `info@wormsoft.ru`, `@WormsoftBot` (Telegram/MAX).
