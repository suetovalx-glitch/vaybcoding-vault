**Время:** ~03:00 (ночная сессия)
**Ассистент:** MiniMax-M3 (wormsoft)
**Канал:** pi-coding-agent CLI (chat)

## Контекст

После создания [[wiki/concepts/dual-agent-stack]] пользователь прислал ссылку на биллинг `https://my.hshp.host/billmgr#/vds/item/1950834/access` и сказал: «посмотри этого провайдера, 2 VPS здесь». VPS-1 (Hermes) уже куплен у AdminVPS, Финляндия — но IP/логин/порт не присланы. Цель разговора — зафиксировать провайдера VPS-2, тариф и подготовить заметки под деплой.

## Что обсудили

### Блок 1. Что я могу и чего не могу с чужой авторизацией

- BILLmanager — это SPA с client-side routing (`#/vds/item/...`), простой `fetch_content` его не берёт.
- Заходить в чужой биллинг через авторизацию пользователя **не буду** (это явный шаг через его сессию — даже с подтверждения это плохая практика для ассистента).
- Собрал публичную картину через `ai-wormsoft_web_search` (kreohost.ru, обзоры, отзывы otzovik).

### Блок 2. Что известно про hshp.host

- Российский хостер с 2021 года, BILLmanager + VMManager + KVM, локации RU/DE/FI/FR.
- Тарифы 2026: MSK-1 (300 ₽, 1/2/30 ГБ), MSK-2 (600 ₽, 2/4/60 ГБ), FI-RZ-1..6 (350–2800 ₽), DE-E0..6 (209–8000 ₽).
- **Репутация:** kreohost 2.6/5, otzovik 1.6/5, **только 10% рекомендуют**. Главные жалобы — долгая активация (1–14 дней против заявленных 120 секунд), медленная поддержка, возврат денег только бумажным письмом.
- **Позитив:** низкие цены, AMD Ryzen 5950X в Финляндии, безлимитный трафик, AntiDDoS включён.
- **Юр. лицо:** ИП Шарапов Никита Александрович, Ростов-на-Дону.

### Блок 3. Выбор тарифа для VPS-2

- Пользователь подтвердил: **DE-E2** (тариф).
- DE-E2 = 2 vCPU / 4 ГБ RAM / 60 ГБ NVMe / 500 Мбит/с / ~600 ₽/мес.
- Заявленная локация — Германия, по факту (по отзывам) — Финляндия.
- Это **точно под наш конфиг** для pi-coding-agent: Chromium + Node 22 + 6 MCP-серверов требуют 4 ГБ RAM.

## Принятые решения

- **VPS-2 = hshp.host DE-E2 (id 1950834, ~600 ₽/мес).** Зафиксировано.
- **VPS-1 = AdminVPS (Финляндия).** Зафиксировано, но без параметров доступа.
- **Фронтматтер `VPS/pi-agent.md` хранит несекретные метаданные** (провайдер, тариф, локация, характеристики). **Секреты** (IP, user, password, ssh-key) — заполняются пользователем вручную, **не пишутся в vault**. Через Templater команда SSH подставляется из frontmatter динамически.
- **Заметка `VPS/hermes.md` пока не создаётся** — ждём от пользователя IP/логин/порт для AdminVPS.
- **Репутация hshp.host низкая (2.6/5, 10% рекомендуют).** Принято как допустимый риск для экспериментального деплоя. Для коммерческого 24/7 — высокий риск. Зафиксировано в `Contradictions / Uncertainty` entity-страницы.
