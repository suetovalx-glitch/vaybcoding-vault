## Контекст

Пользователь попросил проверить провайдера AdminVPS. Использовал `web_search` для сбора данных с официального сайта и обзоров (EasyLinkLife, hostprofi, AIlist, VPSindex, Хабр).

## Что обсудили

- **TL;DR:** AdminVPS подходит для нашего сценария, с оговорками.
- Плюсы: Варшава (LIM DC3, Tier 2+, пинг до Москвы 30–40 мс), KVM без оверселлинга, NVMe, оплата картой РФ, активация за 1 минуту.
- Минусы: нет API/Terraform, нет почасовой оплаты, бесплатный тест только для юрлиц.
- Тарифы на Варшаве: Promo 499 ₽ (1 vCPU / 2 ГБ / 15 ГБ), Micro 799 ₽ (2 / 4 / 30), Start 1 289 ₽ (4 / 8 / 60).
- Скидки: −10/15/20% за 6/12/24 мес, промокоды `ISP30DAY` (бесплатный ispmanager), `AILIST` (−60% на первый заказ).
- Прямой доступ к OpenAI/Anthropic с Варшавы — работает, потому что европейский IP.

## Принятые решения

- Рекомендованный тариф: **Micro Варшава 799 ₽/мес** — 2 vCPU / 4 ГБ / 30 ГБ.
- Альтернатива: Start 1 289 ₽/мес для запаса под Docker/Quartz.
- Запасной план: при блокировке зарубежного IP — российский API-шлюз (GPTunnel), заменить 2 env-переменные.
